# Project Scenario – Boston Housing Analysis

Notebook zawiera eksploracyjną analizę danych (EDA) oraz serię testów statystycznych przeprowadzonych na klasycznym zbiorze Boston Housing. Celem projektu jest ocena wpływu wybranych zmiennych na medianową wartość nieruchomości (MEDV) oraz interpretacja wyników w kontekście analizy rynku.

## 🔍 Zakres analizy

1. **T-test** – Czy istnieje istotna różnica w medianowej wartości domów położonych nad rzeką Charles (CHAS)?
2. **ANOVA** – Czy wartość domów różni się w zależności od udziału jednostek wybudowanych przed 1940 rokiem (AGE)?
3. **Korelacja Pearsona** – Czy istnieje zależność między stężeniem tlenków azotu (NOX) a udziałem terenów niemieszkaniowych (INDUS)?
4. **Regresja** – Jaki wpływ ma dodatkowa odległość od centrów zatrudnienia na wartość nieruchomości (DIS)?
